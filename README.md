# He-Cares Funeral Services Website

A responsive static website for He-Cares Funeral Services.

## Files
- `index.html` — complete website structure
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, animations and WhatsApp enquiry form
- `assets/he-cares-logo.jpg` — branding asset cropped from the supplied flyer

## Run locally
Open `index.html` in a browser.

For VS Code, you can use the Live Server extension.

## Firebase Hosting
1. Install Firebase CLI.
2. Run `firebase login`.
3. Run `firebase init hosting`.
4. Select this project folder as the public directory.
5. Use `index.html` as the entry point.
6. Run `firebase deploy`.

Before publishing, replace the placeholder Facebook `#` link with the official Facebook page URL and confirm the website domain.
